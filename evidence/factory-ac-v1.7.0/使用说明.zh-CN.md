# Cardputer-Adv 美的空调遥控 v1.7.0

默认采用已验证开关可用的方案 B / COOLIX，直接进入正式遥控页。v1.7.0 的调温、风速、上下摆风及退出后重新进入的设定保留，已由用户实机确认。其他模式与附加功能仍须按机型逐项验证；软件测试通过不代表全部实体功能都已验收。

## 常用按键

从原厂菜单打开 **红外遥控**（不是红外工具）。屏幕不是触屏；使用实体键盘。

| 按键 | 操作 |
|---|---|
| 上 `;`、下 `.` | 选择温度、模式、风速 |
| 左 `,`、右 `/` | 调整选中的设定；温度到17/30℃时不再越界 |
| 键盘右侧 **OK** 回车 | 应用当前设定并开机；红外初始化失败时，先重试初始化，再按一次才发送 |
| **1** | 按当前设定开机 |
| **0** | 关机 |
| **Tab** | 打开更多控制 |
| **Esc / Tab**（子页面） | 回到正式主控页 |
| 顶部 **G0** | 返回原厂菜单，正在发送时先取消本机事务 |

方向键调整只是修改待发送设定，不会立即开空调。页面显示“设定值”，不是从空调读回的状态。送风模式显示 `--`，不调温；原温度会保留，切回其他模式仍可使用。设定中的温度、模式、风速写入本机独立偏好，正常情况下退出或重开后恢复；不会自动发送。

## 更多控制

按 Tab，用 `;` / `.` 上下选择，按 OK 执行。列表可滚动：

1. 上下摆风／切换。
2. 摆风点动／一次。
3. 睡眠／切换。
4. 强力／切换。
5. 屏显／切换。
6. 清洁／切换。
7. 兼容测试 A/B/C（固定26℃制冷自动风，方向键切方案，1开0关）。
8. NEC 手动（两个完整十进制地址/命令0～255，如 `16,1`）。

附加功能不会偷偷先发开机。它们没有真实状态回读；同一按钮通常是切换，想恢复时再操作一次并观察空调。具体机型可能不接受其中某项。定时、0.5℃、ECO、独立左右摆风未提供，原因与验证边界见同目录说明。

## 实机核对

1. 默认制冷26℃自动风时按1，确认仍可开机。
2. 默认焦点为温度，按左 `,` 调到25，再按OK，观察空调设定。
3. 按下 `.` 两次选风速，再按右 `/` 调为低风，OK应用，观察风速变化。
4. Tab进入更多，第一项按OK检查摆风；其他功能逐项按需验证。
5. G0退出后重新进入，确认温度/模式/风速恢复；若要验证重启保存，可关机重开后再次查看，不用重新配网或登录。
6. 最后按0检查关机。

## 文件与更新

- `Factory-v1.7.0-ac-app.bin` 是**仅原厂app更新**，地址 **0x340000**，只适用于已经安装本项目ESP32-S3/8MiB双固件布局的设备；不能按0地址整机固件烧写。
- `Factory-v1.7.0-ac-source.zip` 含源码、固定上游参考与许可证、真实源码主机回归测试。构建使用ESP-IDF 5.4.2 / ESP32-S3，原有双分区保持。
- 现有设备按本项目原有安装教程，选择上述app与地址只更新原厂分区。**不要擦除全片或同时重写NVS、分区表、otadata、Ekko分区。**首次安装其他布局的机器需要先用对应正式整机安装包建立本项目布局，不能直接写这个app。
- `flash-verification.json` 记录本次实际刷入后的整机读回核对结果；`实机测试结果.json` 区分设备发送与用户观察到的空调响应。
- `SHA256SUMS.txt` 校验此目录文件。整机私有备份、NVS、Wi-Fi密码、账号和录音不放入公开包。
- 回退基线保留为此前已验证B开关可用的v1.6.2原厂app，同样只更新0x340000。

已知限制及每项发现的严重性/置信度见 `控制功能与验证边界.zh-CN.md`。退出时若偏好写入失败只记录日志；发送完成后写入失败有页面提示，控制功能仍可继续使用。
