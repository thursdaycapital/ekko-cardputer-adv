# 原厂菜单中文速查

方向键选择，键盘右侧 OK 进入，顶部 G0 返回原厂菜单。

| 中文菜单 | 原名称 | 用途 |
|---|---|---|
| EkkoStudio | EkkoStudio | 进入 16 个 Agent 的选择与 AI 聊天；连接电脑上的 Studio |
| 无线扫描 | Scan | 查看附近 Wi-Fi 名称和信号强弱；连接网络要到“网络设置” |
| 录音回放 | Record | N 录音，OK 停止保存到 SD 卡；列表 OK 回放，退出后可再读文件 |
| 设备聊天 | Chat | 通过 ESP-NOW 与兼容设备收发文字，不是 AI 聊天 |
| 红外遥控 | Remote | 输入 NEC 红外地址和命令并发送；接收设备要支持对应协议 |
| 脚本终端 | REPL | 输入 Python 代码，按回车执行，适合编程实验 |
| 网络设置 | SetWiFi | 搜索、选择、连接并保存 2.4GHz Wi-Fi，与 EkkoStudio 共享配网 |
| 时钟 | Clock | 联网校时后显示北京时间；未校时时显示开机运行时长 |
| 键盘控制 | Keyboard | 把 M5 当作蓝牙或 USB 键盘，给连接的电脑等设备输入文字 |
| 运动传感器 | IMU | 查看设备的加速度、角速度，观察移动和转动数据 |
| 存储卡 | SDCard | 查看存储卡信息，并检查是否可以写入 |
| 红外工具 | StringIR | 通过 StringIR 协议发送文字与显示样式，需要兼容的接收设备 |
| LoRa 电台 | LoRaChat | 使用 LoRa 扩展模块收发消息，需要 Cap LoRa868 模块 |
| GPS 定位 | GPS | 使用扩展模块查看经纬度、速度等信息，需要对应的 GPS/LoRa 扩展硬件 |

## 换 Wi-Fi

进入“网络设置”，按 `;`／`.` 选择网络，OK 进入密码页，再按 OK 连接。`R` 重新扫描、`M` 手动输入网络名、`Tab` 清空输入。看到“已连接并保存”后再回菜单，进入 EkkoStudio 即可，不用在两个固件里分别配网。

## 进入 AI 聊天

原厂菜单选择 EkkoStudio → OK → 方向键选 Agent → OK。输入文字后 OK 发送，按住 Fn＋空格说话、松开发送。Ctrl＋空格切换中文/英文输入，Tab 切换到历史浏览。

聊天页 Esc 返回 Agent 首页，Agent 首页 Esc 返回原厂菜单。原厂菜单按 Q 可切换静音模式；顶部划叉的麦克风图标表示静音状态，不表示 Wi-Fi 未连接。

GPS、红外、LoRa 等扩展功能沿用原厂逻辑，本次做了汉化和字体适配，没有把未接外设的主机测试当作外设验收。完整已知问题见“验证与问题说明”。
