# 双固件中文 / Fusion Pixel 更新教程

本包是 Cardputer-Adv（ESP32-S3、8MiB Flash）现有双固件布局的应用更新。包含定制原厂菜单 `factory-ekko-v1.6.0-zh` 和 EkkoStudio `v8.3.0-zh-fusion`。硬件型号和分区不同的设备不能直接照此地址安装。

## 文件与地址

| 文件 | 写入地址 | 分区上限 |
|---|---|---|
| firmware/EkkoStudio-v8.3.0-zh-fusion-app.bin | 0x10000 | 0x330000 |
| firmware/Factory-v1.6.0-zh-app.bin | 0x340000 | 0x400000 |

本包没有整机私有镜像、NVS、账号密码或绑定数据。它也不包含首次安装所需的启动器/分区表；只适合已经安装本项目双固件布局的设备更新。原机完整备份必须私下保存，不能放到公开仓库。

## 更新步骤（macOS / Linux）

在解压后的文件夹打开终端。先用带数据功能的 USB 线连接 M5，然后安装烧录工具：

```sh
python3 -m venv .flash-venv
source .flash-venv/bin/activate
python -m pip install 'esptool==4.12.0'
python -m serial.tools.list_ports
```

记录实际串口名。下列 `/dev/cu.usbmodemXXXX` 必须换成上一步的端口；不要直接照抄占位符。若自动进入下载模式失败：关电源，按住顶部 G0 插入 USB，约两秒后松开。

先在本机私有目录备份完整 8MiB：

```sh
mkdir -p private-backup
chmod 700 private-backup
python -m esptool --chip esp32s3 --port /dev/cu.usbmodemXXXX --baud 1500000 read_flash 0x0 0x800000 private-backup/before-update.bin
```

校验发布文件（macOS）：

```sh
shasum -a 256 -c SHA256SUMS.txt
```

确认备份成功、设备已是本项目布局后，只写两个 app：

```sh
python -m esptool --chip esp32s3 --port /dev/cu.usbmodemXXXX --baud 1500000 --before default_reset --after hard_reset write_flash --flash_size keep 0x10000 firmware/EkkoStudio-v8.3.0-zh-fusion-app.bin 0x340000 firmware/Factory-v1.6.0-zh-app.bin
```

此命令不擦除整片 Flash，不写 NVS、OTA 数据、分区表或文件系统。刷写完成后通常回到原厂菜单；选择 EkkoStudio，按键盘右侧 OK 进入。这里只支持“现有双固件更新”，不要把 app 文件作为从 0 地址开始的整机镜像烧录，也不要在管理页 OTA 上传原厂 app。

## 中文菜单与常用操作

原厂菜单：EkkoStudio、无线扫描、录音回放、设备聊天、红外遥控、脚本终端、网络设置、时钟、键盘控制、运动传感器、存储卡、红外工具、LoRa 电台、GPS 定位。

- 原厂四方向选应用、OK 进入、顶部 G0 返回；“网络设置”连接和保存 Wi-Fi，保持与 EkkoStudio 共享配网。
- EkkoStudio 首页四方向选 16 个 Agent，OK 进入聊天；聊天页 Esc 返回 Agent 首页，首页 Esc 返回原厂菜单。
- 输入文字后 OK 发送；中文 Ctrl＋空格切换输入语言；Fn＋空格按住说话、松开发送；Tab 进入历史浏览后用上下方向翻阅。
- 固定文案使用 Fusion Pixel 12px 兼容字体；品牌、物理键名、SSID、文件名、用户消息和内部协议名保留。字库附 180 个原 efont12 兼容字，不能宣称覆盖所有 Unicode。
- 原生配网、设备、登录、配置档管理网页也已中文化，并从设备本地载入 Fusion 网页字体。
- 语音缓冲逻辑保持已验收 v8.2.4.4 的实现。远程功能仍受电脑、对应 Agent、官方中继及当前网络可用性影响。

## SD 录音

原厂菜单进入「录音回放」：N 新录音，OK 停止保存，列表 OK 回放；上下选择旧文件，G0 保存并返回。文件在 FAT32 卡的 /RECORD/ 目录。已实测保存后回放和退出重进回放正常，细节见《SD录音使用说明》。

## 源码构建

`双固件源码.zip` 内两套源码分别构建，不混用工具链：

- factory：ESP-IDF 5.4.2，运行 `idf.py build`。
- ekko：PlatformIO，运行 `pio run -e cardputer-adv`；依赖版本已固定。

字体许可、上游来源、覆盖清单、可重现步骤和主机测试均随源码保留。主机测试、软件画布截图和编译结果均不代替真实外设或 LCD 验收，具体范围见验证与问题说明。
