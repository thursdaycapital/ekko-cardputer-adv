# Cardputer-Adv SD 录音与回放 v1.6.0

原来的「录音回放」只保留内存里最近约 1 秒，不会自动保存到 SD 卡。此版改为 SD 文件录音，正常停止后退出或重启都能保留，随后从列表回放。

## 操作

1. 关机后插入可读写的 FAT32 microSD 卡，再开机。固件不会格式化卡，也不会覆盖旧录音。
2. 原厂中文菜单 →「录音回放」。首次没有文件时按 **OK** 开始；有文件时按 **N** 开始一段新录音。
3. 说话后按 **OK** 停止并保存，等待返回文件列表。录音中按顶部 **G0** 也会先保存，再返回原厂菜单。
4. 列表用 **上 `;`／下 `.`** 选择，按 **OK** 回放；播放时按 **OK** 停止，**G0** 返回原厂菜单。
5. 录音在卡的 **`/RECORD/REC00001.WAV`** 等文件中，按序生成。关机后取卡，用电脑可播放或复制文件。

录音格式：16kHz、16-bit、单声道 PCM WAV，约 **1.92MB/分钟**（十进制）。录音和播放使用固定 24KiB PCM 缓冲，不把整段录音放进内存。列表显示最新 64 条有效录音，更早文件仍保留在卡上，电脑可读取。目录或文件名被占用会报错，不会删除用户文件。序号到 99999 后会提示错误，不循环覆盖。

没有卡、无法写入、卡满、文件读取失败会显示错误；处理后按 OK 重新检查。录音期间不要拔卡。正常停止会写好 WAV 头并同步；每约 1 秒也会更新一次头部。突然断电/强制退出/拔卡仍可能损失最后一段或损坏当前文件，不能把它当成断电保护。

## 安装边界

`Factory-v1.6.0-zh-app.bin` 是**已有本项目双固件布局**的原厂分区更新文件：ESP32-S3 / 8MiB Cardputer-Adv，更新地址 **0x340000**。它不是从 0 地址烧录的完整镜像，不用于普通 Cardputer，也不是 EkkoStudio OTA 包。

本次 USB 更新只写 factory app，完整读回的核对结果见 `flash-verification.json`。EkkoStudio app、NVS 配网/绑定、OTA 数据、分区表与其他区域需与本次刷前备份完全相同。私有全量备份留在本机，不放入这个交付目录。

## 验证状态

构建、宿主测试、烧录读回与实体 SD/听感分别记录在 `状态.json`；宿主模拟不能证明 SD 卡和扬声器已经实际成功。用户已确认：录音保存后首次回放正常，G0 退出菜单后重进再回放也正常。本次录音阶段串口未捕获有效日志，实体结果依据用户实测反馈，不虚构采样字节数、峰值或播放日志；关机重开后的回放尚未另做实体测试。此前的旧版完整包作为历史保留。
