# 发布包隐私说明

本公开发布副本已将本机用户名/主目录/工作区绝对路径、实际测试网络名及热点名替换为通用占位或匿名描述。本仓库在既有公开脱敏版本上更新，不加入原开发仓库的私人Git历史。电脑端仅附经检查的源码补丁。提交者使用已确认GitHub账号的官方noreply邮箱。

没有加入个人Studio运行目录、账号密码、API Key、登录JWT、原机NVS或私人整机备份。新整机镜像的NVS/启动选择/未使用数据区均全FF；更新app保持已实机验收SHA，不会随包携带某台设备的绑定。

第三方源码许可证中的真实作者署名/公开邮箱、代码示例的IP/MAC、公开CA证书机构信息保留。固件中的上游预编译工具链断言路径来自官方SDK，非本机用户信息；不通过修改已验收二进制删除这些字段。上游图片的个人位置/作者元数据已移除，像素保持一致，图片与校验变更见 evidence/public-release-validation.json；启动视频嵌入的60帧保留验收原字节，只有格式头，无个人EXIF/GPS字段。

静态检测只能支持“未检出个人凭据”，不声称证明任意未知秘密绝对不存在。不要把日后自行生成的私人备份、`.env`或个人配置提交到仓库。

上游 Arduino WiFiClient 示例内的读写 API Key 字面量已替换为明确的 EXAMPLE 占位字符串；它们来自公开上游示例，不是本机账号凭据。对应示例不参与当前设备固件链接。固件内出现的 PRIVATE KEY 标头均为以NUL结尾的TLS解析常量，没有PEM私钥载荷。
