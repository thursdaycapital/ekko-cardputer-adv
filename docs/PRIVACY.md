# 发布包隐私说明

本公开发布副本已将本机用户名/主目录/工作区绝对路径、实际测试网络名及热点名替换为通用占位或匿名描述。新仓库仅含清理后的首次提交，不包含本地开发Git历史。提交者使用已确认GitHub账号的官方noreply邮箱。

没有加入个人Studio运行目录、账号密码、API Key、登录JWT、原机NVS或私人整机备份。新整机镜像的NVS/启动选择/未使用数据区均全FF；更新app保持已实机验收SHA，不会随包携带某台设备的绑定。

第三方源码许可证中的真实作者署名/公开邮箱、代码示例的IP/MAC、公开CA证书机构信息保留。固件中的上游预编译工具链断言路径来自官方SDK，非本机用户信息；不通过修改已验收二进制删除这些字段。上游图片的个人位置/作者元数据已移除，像素保持一致，变更记录见privacy-sanitization.json。

静态检测只能支持“未检出个人凭据”，不声称证明任意未知秘密绝对不存在。不要把日后自行生成的私人备份、`.env`或个人配置提交到仓库。
